# Lij Dawud (ልጅ ዳውድ) — Creator Media Kit & Brand Collaboration Platform

Official creator website and brand partnership platform for **Lij Dawud**, prominent Ethiopian digital entertainer and TikTok creator based in Addis Ababa, Ethiopia.

## 🚀 Live Demo & Hosting
Built with Vite + React + TypeScript + Vanilla CSS. Ready for one-click deployment on **Vercel**, **Netlify**, or any static/edge hosting.

### Vercel Deployment Instructions
1. Import this repository in your Vercel Dashboard: `https://github.com/webseyf/lijdawud`
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!

---

## ✨ Features
- **Editorial Design System**: High-contrast dark mode tailored for Ethiopian digital entertainment with Imperial Gold accents and custom Ethiopic typography (`Noto Sans Ethiopic` & `Noto Serif Ethiopic`).
- **Creator Hero Section**: Real creator portrait of Lij Dawud, positioning statement, and direct conversion CTAs.
- **Playable TikTok Video Showcase**: 6 selected TikTok video embeds with on-demand playback, optimized to prevent rate-limiting and overload protection.
- **Advertising Packages**: 4 clear commercial tiers (Sponsored TikTok Video, Creative Brand Integration, Multi-Video Series, Custom 360° Collaboration) with one-click form preselection.
- **Collaboration Process**: 4-step workflow (Brief → Concept → Production → Publish).
- **Creator Biography**: Overview of content themes, Habesha comedy roots, and verified social channels.
- **Business Inquiry & Booking Form**: Interactive client-side validation, package preselection, duplicate protection, instant reference code generation (`LD-XXXXXX`), and summary copy action.
- **Bilingual (English & አማርኛ)**: First-class language switcher with complete UI translation.
